# Weather API CLI

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)

A small command-line weather app that retrieves current conditions for a city from OpenWeatherMap and displays the temperature, humidity, and description.

## Setup

Install Python and the `requests` package, then add an OpenWeatherMap API key in `weather_api.py`:

```bash
pip install requests
```

## Run

```bash
python main.py
```

Enter a city when prompted. An internet connection and a valid API key are required.
